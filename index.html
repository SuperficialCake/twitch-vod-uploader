Twitch VOD Uploader

A personal tool for archiving Twitch broadcasts to YouTube.

What it does

Twitch VOD Uploader is a small program run by SuperficialCake for personal use. When a Twitch broadcast on jezzabear ends, it downloads the saved broadcast (VOD) from Twitch and uploads it to the YouTube channel of the person who authorised it. It runs on the owner’s own computer or server and is not a public service. There are no other users, accounts, ads, or tracking.

How it uses YouTube

This application uses YouTube API Services. It requests a single permission, youtube.upload, which allows it to upload videos to the authorised YouTube channel. It does not read the channel’s existing videos, comments, subscribers, or analytics. The channel owner chooses the privacy setting for uploads and can revoke access at any time.

By using this tool you agree to be bound by the YouTube Terms of Service.
