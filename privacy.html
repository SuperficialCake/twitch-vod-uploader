Privacy Policy

Last updated: November 15, 2026

Twitch VOD Uploader is a personal tool, operated by SuperficialCake, that uploads the channel owner’s own Twitch broadcasts to the channel owner’s own YouTube channel.

Use of YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What the application accesses

With the Google account owner’s consent, it requests only the https://www.googleapis.com/auth/youtube.upload permission, which lets it upload videos to the authorised YouTube channel. It does not read the channel’s videos, comments, subscribers, or analytics, and it does not access any other Google data.

What it stores

On the computer where it runs, the application stores (1) an authorisation token so it can keep uploading without a new login, and (2) a list of Twitch video IDs it has already processed. It does not store YouTube video data. Downloaded video files are deleted after upload unless the operator chooses to keep them. No data is shared with third parties, and there are no advertisements, analytics, or cookies.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page, or by running the tool with its --revoke option, which revokes the token and deletes it. Stored data will be deleted within 7 days of a request. Deleting data held by this application does not remove videos from YouTube; videos are removed through YouTube Studio.
